# Example occurrence dataset.

An example occurrence dataset for the Brown Throated Sloth (*Bradypus
variegatus*) downloaded from GBIF with the `spocc` package.

## Usage

``` r
bvariegatus
```

## Format

A data frame with 476 rows and 2 variables:

- longitude:

  The longitude coordinate (x).

- latitude:

  The latitude coordinate (y).

## Source

<https://www.gbif.org/>
